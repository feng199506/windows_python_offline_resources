Python 3.10.11 / Windows amd64 离线套件

独立目录：windows_python_offline_resources/python310_amd64/
不依赖 python312_amd64/ 或其他版本目录。拷到 Windows 后只用本树即可安装。

项值
CPython3.10.11（有 python.org 官方 Windows x64 .exe 的最后一版；其后 3.10.x 仅为源码）
架构amd64（win_amd64 / x86-64）
安装程序runtime/python-3.10.11-amd64.exe（SHA256 d8dede5005564b408ba50317108b765ed9c3c510342a598f9fd42681cbe0648b）
VC++runtime/vc_redist.x64.exe
环境组31
wheel 合计1504（分组存放，torch/TF 等故意重复）
wheel 体积4.64 GiB
本轮已按 win_amd64 + CPython 3.10 下载并写锁定清单；未在 Windows 上安装验证

3.10 已于 2026-10-01 结束安全支持，本套仅用于兼容旧代码。

安装

# 1. 安装 runtime\python-3.10.11-amd64.exe 与 vc_redist.x64.exe
# 2. 选一个环境：
cd environments\01_base_scientific_py310
powershell -ExecutionPolicy Bypass -File .\install_offline_en.ps1 -PythonExe "C:\Python310\python.exe"
.\.venv\Scripts\python.exe .\check_environment_en.py

使用 requirements_lock_en.txt（含传递依赖），不要只装 direct 清单。

限制

  • 未在目标 Windows 上创建 venv、未 pip install、未 import。
  • 无 CUDA / GPU wheel。
  • GPflow（07b）锁定 TF 2.16.2 + numpy<2，不能与 07 的 TF 2.21 混装。
