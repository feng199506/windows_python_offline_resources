Windows 通用科研 Python 离线环境库（离线首页）

本页在浏览器中直接打开即可（无需联网）。所有本地链接指向解压后的同一目录；http(s) 链接是上游来源，需要联网。每个 Markdown 说明都有同名 .html 版本，每个 CSV 都有同名 .html 表格视图（含中文的原始 CSV 已加 BOM，可用 Excel 直接打开）。

本库只做了静态检查，未在 Windows 上实际安装验证。安装方法见 Windows 安装步骤。只需拷贝一棵树（3.10 或 3.12）。若只下载了部分二进制包，指向未下载 wheel 的链接会打不开，属正常。
